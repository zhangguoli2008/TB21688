# 13 供应商、货源、SKU匹配及AI扩展

## 第一原则
同款不能只靠标题/图片判断，商品必须满足品牌/型号/颜色/尺寸/材质/数量/包装/适用地区/发货时效与合规要求。AI候选≠已确认SKU。

## 数据对象
- `SalesSku`: 店铺SKU、属性列表、规格、图片引用、数量单位。
- `SupplierSku`: 供应商商品、规格、库存、可售区域、发货时效、相关密文能力。
- `SkuMapping`: tenant、store、salesSku、supplierSku、version、CONFIRMED/REVIEW/PAUSED、确认人。
- `SupplierQuote`: 含税商品价、运费、优惠/最小起订、币种、有效时间、来源。
- `SupplierScore`: 历史报价稳定、按时发货、退款等聚合指标（数据不充分时不显示评分）。

## V1匹配
1. 对已确认映射按优先级加载供应商。
2. 检查供应商能力、下游平台密文履约支持、供应区域、库存及报价时效。
3. 若首选失败，可扫描**已确认的备选映射**；不能未经人工确认切换陌生SKU。
4. 以完整到手采购成本而非单件标价排序：商品单价×件数+运费+费用。
5. 备选供应商需要单独对齐订单来源平台的面单/密文支持。
6. 记录选定供应商理由、报价时间、所有候选和排除原因（脱敏且许可的数据）。

## V2 AI候选
- 输入：获得许可的商品图片/标题/属性；不抓取受限平台数据。
- 可使用文字语义召回 + 图像向量召回 + 属性精确匹配 + 重排。
- 过滤：品牌不一致、型号不一致、尺寸单位换算错误、颜色不符、套餐数量不同、侵权/管制商品。
- 输出：候选商品、匹配理由、置信度、差异项，**默认需商家点击确认**。
- 训练/向量数据必须遵守图片授权、平台合同和删除请求。

## 利润计算例子
销售实收 99元=9900分；供应商商品价35元=3500分；运费5元=500分；预计平台费7元=700分；预计售后预留3元=300分，则预计毛利4900分。若应退货、部分优惠分摊、补贴或成交服务费实际差异，实际利润与预计利润必须分开计算。

## 防错购检测
- 首购新供应商人工审。
- 价格涨幅超店铺阈值人工审。
- 库存不足、产品下架、最小起订不满足禁止自动采购。
- 不同品牌同款、商标/知识产权不明、规格单位变化人工审。
- 最新报价过期重新报价；新的创建订单金额高于报价快照必须暂停。
