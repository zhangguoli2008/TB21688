# 21 公开资料来源与核查记录（截至2026-10-20）

以下仅作为产品需求调研的公开信息来源，不自动等于任何API授权、合作关系或资质获批；正式开发请核对实际入驻平台最新文档/公告。

1. 乐客一件代发官方公开帮助文档，官网页面显示2026-08-25更新v1.1.2：
   https://www.lekes.cn/doc/yjdfhelp.html
   可参考其模块分类：一键下单、店铺管理、店铺利润、售后中心、订单打印、商品关联、账号管理、自动采购设置、数据大屏、操作日志。**只作为业务对标**。
2. 抖店开放平台首页/文档中心：
   https://op.jinritemai.com/docs
   https://op.jinritemai.com/
   公开列有服务商应用、商品、订单、物流、售后等分类及2026年公告。
3. 抖店店铺授权介绍（OAuth2.0）：
   https://op.jinritemai.com/docs/guide-docs/133?docLabel=1
   公开强调授权是“应用与店铺”的关系。
4. 抖店收费接口与类目FAQ：
   https://op.jinritemai.com/docs/guide-docs/84/7277?docLabel=&from=list
   订单列表和其他API的实际收费/额度应按应用控制台和当期公告核实。
5. 抖店商品类目管理规范：
   https://op.jinritemai.com/docs/guide-docs/1029
   商品供应链类目存在定向邀请与具体资质限制，申请前须官方确认为本产品适用类目。
6. 淘宝用户授权介绍：
   https://developer.alibaba.com/docs/doc.htm?articleId=102635&docType=1&treeId=154
   淘宝商家数据读取须取得应用所需授权。
7. 淘宝开放平台《1688分销业务密文方案》（2025-06-19）：
   https://developer.alibaba.com/docs/doc.htm?articleId=122128&docType=1&treeId=1
   公开规定淘宝/天猫密文订单向1688采购需核验是否支持淘宝电子面单，提及 `alibaba.fenxiao.productInfo.get` 与字段 `encryptLogisticsOrderSupportChannel`。
8. 1688开放平台：
   https://open.1688.com/
   页面与接口可能有登录/权限限制；自动支付正式能力需走应用/商务确认，不能用竞品宣传替代权限核实。
9. 拼多多开放平台：
   https://open.pinduoduo.com/
   当前本方案**未验证**普通买家第三方API创建订单及自动付款，请按官方商务答复决定后续接入。

## 信息置信度
- 高：官方公开说明存在某类能力，且与该平台角色一致。
- 中：竞品官方帮助文档提及功能，但只能证明厂商公开声称该功能。
- 未验证：实际业务应用是否具备具体scope、真实采购/支付API、跨平台消费者隐私流转权限。

## 版本更新流程
在每个真实Provider实现PR合并前，新增 `docs/platform-evidence/<平台>-<日期>.md` 记录审批截图/工单号、接口版本、测试环境、授权范围和生产开关审批结果。无证据禁止将Mock标记为ProductionReady。
