# 25 项目各阶段验收清单

给项目负责人逐项勾选。未满足的项目不得通过该里程碑。

## M0 骨架
- [ ] 前端Vue3和后端SpringBoot从空库可启动。
- [ ] PostgreSQL迁移、Redis、RabbitMQ和Mock服务运行正常。
- [ ] `AGENTS.md`约束已贯彻，生产接口全部默认关闭。
- [ ] 租户隔离、登录、RBAC与至少一个错误API测试通过。
- [ ] CI可报告实际执行的构建、测试结果。

## M1 订单
- [ ] 两租户同外部订单号不会串数据。
- [ ] 重复、乱序订单事件处理正确。
- [ ] 权限不足用户无法读取其他店铺订单。
- [ ] 授权过期/撤销后停止新同步和敏感写操作。

## M2 SKU与采购
- [ ] 只有人工确认且有效的SKU映射可触发自动采购。
- [ ] 报价过期、运费过高、库存不足均被安全阻塞。
- [ ] 采购创建超时进入未知状态，不重复创单。
- [ ] 同销售子项无超数量采购。

## M3 双付款模式
- [ ] MANUAL、AUTO、RULE_BASED皆有单独E2E演示。
- [ ] 生产无签约时AUTO功能不能实际执行。
- [ ] UNKNOWN后不发第二次扣款/不开放人工重付。
- [ ] 付款策略提高上限需要相应权限/审计。
- [ ] 并发订单不会超日累计限额。

## M4 履约售后
- [ ] 拆单、多包裹、物流回填、异常补偿可追踪。
- [ ] 退款处理中阻止不合理继续采购。
- [ ] 报表预计与实际利润区分、能追溯到流水。

## M5 准商用
- [ ] 关键安全用例T-001~T-025通过。
- [ ] 日志/导出脱敏，端点权限测试通过。
- [ ] 备份、恢复、监控、急停/灰度开关已经演练。
- [ ] 套餐、角色、审计和异常任务中心可用。
- [ ] 正式文档没有未经证实的渠道能力宣传。

## M6 真实平台
- [ ] 每条外部API与签约有真实权限及合同证据。
- [ ] 平台最新隐私/密文/服务商准入审批通过。
- [ ] 淘宝/抖店订单和1688采购链路按官方sandbox和试点验证。
- [ ] 真实自动支付经过最小金额、签约、对账和停付验证。
- [ ] 拼多多未获批则保持功能不可用。
- [ ] 生产上线负责人、技术、安全/合规审批人签字。
