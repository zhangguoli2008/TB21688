# Codex M2：SKU映射、采购报价和采购意图

只做SP-201~SP-204。重点阅读 `docs/13_货源与AI匹配.md`、`docs/10_支付方案与风控.md`。

1. 实现商品SKU映射`REVIEW/CONFIRMED/PAUSED`，记录确认人、时间、版本；支持多个已确认备选供应商。
2. Mock Supplier支持商品价、库存、运费、是否支持密文履约、报价有效期，且可配置缺货/涨价/超时。
3. 采购规则引擎根据店铺、销售子项、商家限额/利润判断，产出结构化允许/阻塞原因。
4. 对可采购子项生成唯一PurchaseIntent，并异步创建Mock PurchaseOrder；外部创单超时进入CREATE_UNKNOWN后查单，不盲目重下。
5. 前端SKU映射对照、货源候选审核和采购单列表。
6. 测试：无映射不采购、库存不足不采购、金额分处理正确、跨租户隔离、采购唯一性、报价变化阻断。

不要加入AI模型，也不要为不明来源的商品构造所谓真实1688低价数据。提供可重复的Mock数据演示。
