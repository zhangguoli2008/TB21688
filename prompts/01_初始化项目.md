# Codex M0：项目初始化与基础安全

请按 `AGENTS.md` 和 `docs/18_开发里程碑与任务池.md` 实现SP-001~SP-005。

## 交付
- 建立可运行monorepo：`apps/api` Java21 Spring Boot、`apps/web` Vue3/Vite/TS/Element Plus、`infra/docker-compose.yml`。
- 实现 `/api/v1/me` 假数据/演示认证（本地）和统一错误返回；生产不允许硬编码演示密码。
- 实现tenant上下文与RBAC中间件、统一requestId、审计基础模块。
- 从 `database/schema.sql` 拆出Flyway V1基础迁移；在容器中验证迁移可重复启动。
- 创建 `ProviderAdapter` 接口与 `MockSalesAdapter` / `MockSupplierAdapter`，所有真实平台端点禁用。
- 创建Web登录、总览空态、左侧导航、全局404/403，用户可以看到明确的Mock演示提示。
- 建立 CI（后端测试/前端Lint/Typecheck/构建/基本安全检查）。

## 边界
不要调用真实淘宝、抖店、1688或拼多多；不要写浏览器自动支付；不要将示例密钥写入Git。`schema.sql`是设计草案，实施迁移时需兼顾数据约束并记录改动理由。

## 完成标准
- `docker compose up --build`可启动（若环境允许）。
- 浏览器能登录到Mock演示环境，并显示当前租户与服务状态。
- `/api/v1/me`遵循OpenAPI；错误响应带requestId。
- 一个用户访问另一个租户模拟资源失败。
- CI通过；README有本地启动命令、演示数据初始化和自动测试说明。
