# 20 官方平台/供应商技术与商务咨询模板

用于正式邮件、工单或电话纪要；提问时提交产品介绍、安全流图和开发主体，不提供生产token。所有结论记录回答时间、答复渠道、文档版本、联系人岗位、截图/回执编号。

## 抖店开放平台咨询
1. 该产品作为“为第三方抖店商家提供订单回流至1688采购”的应用，应申请哪类服务商资质？是否定向邀请？有哪些注册时间/注册资本/保证金/员工要求？
2. `order/searchList`等订单/商品/物流/售后API，服务商应用所需权限与收费/额度是什么？
3. 订单密文履约/第三方分销时可保存及转交哪些字段？是否要求抖店云或其他特定环境？
4. 消息推送频率、验签、接口停用公告、回填接口限制和审计要求是什么？
5. 是否允许应用从抖店服务市场收费？申请/结算过程是什么？

## 淘宝开放平台咨询
1. 本场景应用类型、授权流程、订单读取与发货回填所需API和权限分别是什么？
2. 对接1688分销订单时，密文/电子面单适用哪些店铺与品类？哪些API正式可用？
3. 商家OAuth/SessionKey有效期与撤销通知方式是什么？
4. 聚石塔/奇门、数据落地和生产部署有何具体限制？

## 1688开放平台咨询
1. ISV能否同时服务多商家的1688采购账号？官方推荐的解决方案和app资格是什么？
2. 开放商品查询、图搜、报价、库存、创建分销订单、查询、取消、物流的哪些正式接口？是否需要白名单？
3. 免密支付在该产品场景是否允许由ISV服务端发起？支持何种签约方式、单笔/每日限额？
4. 支持哪些款项支付状态/对账接口？付款调用超时如何判断是否扣款？有无幂等reference字段？
5. 向不同下游平台推送密文代发订单需要什么货源面单支持和字段校验？
6. 采购账号余额/授信、退款和分账是否有规定？

## 拼多多开放平台咨询
1. 有没有**第三方软件代表普通买家采购商品**的公开或商业合作API？如何申请？
2. 如有，是否支持普通消费者商品搜索/价格/库存/创建买家订单/合法自动付款？
3. 平台是否允许跨平台订单密文转交给拼多多供应商？有无相应履约面单能力？
4. 如不存在，请确认能否仅作为货源推荐而由商家在官方平台人工采购。
