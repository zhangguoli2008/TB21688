## 版本与理由

- Java 21；Spring Boot **3.5.16**：遵循基线的 3.x，不自行升 4；Maven Central 与官方 3.5 文档可核实。Spring 3.5 OSS 支持已结束，生产前需另行批准升级至受支持版本或采购商业支持；本轮不宣称商用安全基线达成。
- Maven **3.9.16**（已核实 Maven Central 稳定版并校验下载包 SHA512）；Spring Security、Flyway、PostgreSQL JDBC、Redis、AMQP 由 Boot BOM 统一管理；springdoc **2.8.17** 与 Boot 3.5 兼容，Swagger UI 加载合同源，避免生成第二份合同。
- Vue **3.5.44**、Element Plus **2.14.7**、Pinia **3.0.4**、Vue Router **4.6.4**：满足 Vue3 与现有架构，避免引入新主版本路由/状态接口。
- TypeScript **5.9.3**、Vite **8.3.4**、Vue 插件 **6.0.10**、vue-tsc **3.3.13**；Node **24**。锁定 TS5，避免未经核验的 TS7 兼容变化。Vite 8 与 Vue 插件的 peer 范围匹配本机 Node24。
- ESLint **9.39.5**、@eslint/js **9.39.5**、eslint-plugin-vue **10.11.1**、typescript-eslint **8.72.0**；Vitest **4.1.12**、@vue/test-utils **2.4.6**、jsdom **26.1.0**；图标 **@element-plus/icons-vue 2.3.2**。保留 Node24.12 可运行性，避免 test-utils2.5.1 的传递依赖与 jsdom30 要求更高 Node 小版本。
- PostgreSQL **17.10-alpine**、Redis **8.8.0-alpine**、RabbitMQ **4.1.8-management-alpine**；已核实Docker Hub对应tag，2026-10-21补验已实际拉取运行，详见 `docs/27`。仅本地演示使用生成的伪凭据。
- 精确依赖以 `pom.xml`、`package.json` 和 lockfile 为准，不使用 latest 或浮动前端版本。

核查来源：[Boot 3.5 系统要求](https://docs.spring.io/spring-boot/3.5/system-requirements.html)、[Spring 官方3.5支持记录](https://api.spring.io/projects/spring-boot/generations/3.5.x)、[springdoc 兼容矩阵](https://springdoc.org/)、[Vite Node 要求](https://vite.dev/guide/)、[npm 官方 registry](https://registry.npmjs.org/vue)、[Maven Central](https://repo.maven.apache.org/maven2/org/springframework/boot/spring-boot-starter-parent/maven-metadata.xml)。

## 审查重点

- 未登录、无 CSRF、退出后的旧 cookie 必须失败。
- tenant header/query 不能提升权限，跨租户模拟资源返回 404。
- 客服身份不能访问 reports.read/system.read 资源，直接 API 也返回 403。
- 非演示环境不提供演示登录；真实通道参数不能激活外部调用。
- 数据库空库与第二次迁移、重复 seed 均保持约束且不生成业务数据；网络故障显示错误或真实服务异常状态。
